# Keyboard

`⌘` is `Ctrl` on Linux and Windows. `?` shows this list in the app, and `⌘K` finds any command by name.

## Everywhere

| key | |
|---|---|
| `G` `D` `E` | Library, Develop, Canvas |
| `O` | open files |
| `←` `→` | previous, next photo |
| `⌘Z` `⇧⌘Z` | undo, redo |
| `⌘C` `⌘V` | copy, paste settings |
| `⌘E` | export |
| `⌘K` | command palette |
| `I` | info overlay |
| `L` | lights out |

## Library

| key | |
|---|---|
| `P` `X` `U` | pick, reject, unflag |
| `0`–`5` | rating |
| `6`–`9` | colour label |
| `⌫` | delete |
| `+` `−` | thumbnail size |
| `C` `N` `⇧C` | compare, survey, cull |
| `⌘F` | search |
| `⌥\` | clear filters |

## Develop

| key | |
|---|---|
| `\` | before and after |
| `J` | clipping |
| `Z` | 100% or fit |
| `V` | black and white |
| `R` | crop (`O` cycles the grid) |
| `M` | masking: `L` linear, `⇧M` radial, `K` brush, `B` object, `O` keep the wash |
| `Q` | remove |
| `H` | heal and clone |
| `[` `]` | brush size |
| `⇧⌘R` | reset to the original |
