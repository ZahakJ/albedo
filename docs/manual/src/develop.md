# Develop

The right panel holds the adjustments, top to bottom.

| section | |
|---|---|
| **Profile** | the look: AgX, Linear or a camera profile ([Profiles and lenses](profiles.md)) |
| **Tone** | exposure, contrast, highlights, shadows, whites, blacks; Auto |
| **WB** | temperature and tint, relative to the camera; Auto and an eyedropper |
| **Curve** | a point curve; the target tool adjusts it by dragging on the image |
| **Color** | vibrance and saturation |
| **B&W** | black and white with a mix per hue (`V`) |
| **Mixer** | hue, saturation and luminance for eight hue bands |
| **Grading** | three-way colour wheels |
| **Effects** | clarity, texture, dehaze, vignette, grain |
| **Lens** | the lens profile and manual distortion, CA and defringe; HL toggles highlight reconstruction |
| **Detail** | AI Denoise, sharpening, noise reduction |
| **Remove & Heal** | removal and spot healing ([Remove and heal](remove.md)) |
| **Versions** | virtual copies of the edit |

## Looking at the result

- `\` toggles before and after; a split view compares them side by side.
- `J` shows clipped highlights and shadows.
- `Z` toggles 100% and fit; drag to pan, or use the navigator.
- The histogram follows every change.

## Crop and straighten

`R` opens the crop. Drag the corners, rotate outside the frame or with the straighten slider, and set keystone correction. The crop zooms in just enough that no empty corner shows.

## Presets, copy and paste

The left rail holds built-in looks and your presets; hovering one previews it, a click applies it. `⌘C` copies chosen modules of the edit, `⌘V` pastes them onto the selection. Presets can be exported as albedo files or for Lightroom.

## History, snapshots and versions

Every change is one undo step. Snapshots save the current edit under a name; versions keep alternative edits of the same photo.
